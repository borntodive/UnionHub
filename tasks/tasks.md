# Tasks

Active work items for AI-assisted development. Link task ID in commits/PRs.

## Format

```markdown
### TASK-XXX — Short title

**Status:** todo | in-progress | done  
**Area:** api | apps/mobile | docs | infra  
**Owner:** (optional)

**Context:** Why this change is needed.

**Acceptance criteria:**

- [ ] Criterion 1
- [ ] Criterion 2

**Test plan:**

- [ ] `cd api && npm test -- <pattern>` or mobile equivalent
- [ ] Manual steps if any

**Notes:** Links, decisions, blockers.
```
